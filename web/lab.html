Get your actual trace in VS Code

From the repository root, run this in PowerShell. The JSON goes in your ignored outputs/ folder, not into Git history.

python -m pip install -e .
python -m cyclistics.visual_lab --rate 900 --seed 754 --horizon 300 --blockage-start 45 --blockage-duration 120 --early-clearance-duration 30 --output outputs/visual_lab.json
python -m http.server 8000 --directory web

Then open http://localhost:8000/lab.html and import outputs/visual_lab.json.
