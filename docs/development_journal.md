## Evidence to keep

- Small Git commits that reflect actual decisions or fixes you made.
- Pull request descriptions with the change, why, and test results.
- Test logs/screenshots from your own machine (when useful).
- Experiment configurations/seeds and the datasets used.
- Notes on the decisions you can explain to your professor or an interviewer.

Comments, a development log, and Git history support understanding and traceability;
none of these by themselves prove that all code was independently authored. Follow
course rules and be transparent about assistance where required.
